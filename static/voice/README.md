# Urdu checklist audio

These synthetic recordings are generated from the app's Urdu checklists using
Meta's [MMS Urdu text-to-speech model](https://huggingface.co/facebook/mms-tts-urd-script_arabic)
for this noncommercial project. The model is available under
[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).

Each filename uses the first 16 hexadecimal digits of the SHA-256 hash of the
checklist text before number pronunciation is expanded. The app can synthesize
audio on demand if the source text changes.
